# Git Commands Record

- `git init` — Initialize a Git repository.
- `git status` — Check file changes.
- `git add .` — Stage files.
- `git commit -m "Initial commit"` — Save changes.
- `git push` — Upload changes to GitHub.
- `git pull` — Download updates from GitHub.
- `git branch` — List branches.
- `git merge` — Merge branches.

## Merge Conflict
If a merge conflict occurs, I identify the conflicting lines, edit the file to resolve the conflict, and commit the resolved changes.

If no conflict occurred, I will state that no merge conflict was encountered.
